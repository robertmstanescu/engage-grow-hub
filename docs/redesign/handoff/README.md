# Redesign hand-off

`restyle-drafts.sql` loads the restyled pages into DRAFT columns only
(`site_content.draft_content`, `cms_pages.draft_page_rows`): 12 updates in
one transaction. It never writes a live column. It was generated by
`scripts/redesign/build-restyle.ts` from the live export of 10 Nov 2026 and
must be run exactly as it is, without edits.

`text-diff.txt` is the proof that the restyle changes layout only: every
page reads "same".

Regenerate both from a fresh export before running on a later day; a copy
edit made in the admin after the export would otherwise be lost.
